# 💰 FinanseApp - Умное приложение для управления финансами

**FinanseApp** — это интеллектуальное настольное приложение для управления личными финансами, построенное на современном фреймворке [Flet](https://flet.dev/). Приложение использует искусственный интеллект для анализа ваших финансов и предоставления персональных рекомендаций.

## 🎯 Версия
**v1.0.2-RELEASE** — Обновленная версия с детальным прогнозом по периодам зарплаты и улучшенной синхронизацией данных

### 🚀 **Готовый к использованию исполняемый файл!**
Приложение доступно как готовый `.exe` файл - просто скачайте и запускайте без установки Python!

## 🚀 Быстрый старт

### Вариант 1: Готовый исполняемый файл (Рекомендуется)
1. **Скачайте** `main.exe` из папки `dist/`
2. **Запустите** файл двойным кликом
3. **Начните** управлять финансами!

### Вариант 2: Установка из исходного кода
1. **Клонируйте репозиторий:**
   ```bash
   git clone <repo-url>
   cd FinanseApp-main
   ```

2. **Создайте виртуальное окружение:**
   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # Linux/Mac:
   source venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите приложение:**
   ```bash
   python main.py
   ```

## 📁 Структура проекта

```
FinanseApp-main/
├── main.py              # Основной файл приложения
├── finance_data.json    # Файл с финансовыми данными
├── requirements.txt     # Зависимости Python
├── main.spec           # Конфигурация PyInstaller

│   └── main.exe
├── build/              # Временные файлы сборки
└── reports/            # Папка для экспорта отчетов
```

## 🔧 Сборка исполняемого файла

Для создания собственного исполняемого файла:

```bash
# Установите PyInstaller
pip install pyinstaller

# Соберите приложение
pyinstaller --onefile --noconsole main.py

# Готовый файл будет в папке dist/
```
